# 🛡️ TryHackMe - Cybersecurity 101 Learning Journey

Welcome to my **Cybersecurity 101** repository! This repository serves as a personal documentation hub and proof-of-work for my learning journey through the [TryHackMe Cybersecurity 101 Pathway](https://tryhackme.com/path/outline/cybersecurity101).

Here, I document room-by-room notes, hands-on lab exercises, key concepts, command-line usage, and practical insights as I build a strong foundation in defensive cybersecurity.

---

## 📌 Objectives & Scope

The goal of this repository is to systematically track my progress and build a strong grasp of fundamental security principles, including:

- **Command Line & OS Fundamentals:** Mastering Linux/Windows navigation, user management, Alternate Data Streams (ADS), and scripting.
- **Networking Basics:** Understanding network protocols, packet analysis, ports, and traffic monitoring.
- **Cryptography:** Exploring symmetric/asymmetric encryption, hashing, compliance standards (PCI DSS, HIPAA, GDPR), and historical ciphers.
- **Defensive Operations:** Preparing for SOC Level 1 concepts, log analysis, and incident detection.
